# SVSI & TBG Prototype Webview

Interactive, clickable static prototype for client review. Built from Figma prototype flows (SVSI + TBG Ethical & SQA). All content is **demo data**.

## Live Site

https://marconip2023.github.io/svsi-prototype-webview/

## How To Use

1. Pick a project tab: **SVSI** or **TBG Ethical & SQA**.
2. Open a role card (Buyer, Supplier, Lab, etc.).
3. Click blue hotspots on the screen, or use Prev / Next.
4. Press **H** to show hotspot outlines, **←** **→** to navigate, **Esc** to go back.
